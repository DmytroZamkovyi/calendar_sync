# Calendar Sync

[🇬🇧 English](README.md)

Двостороння (або одностороння) синхронізація між будь-якими двома календарями
Home Assistant (`calendar.*`) з простими правилами для кожного напрямку. Лише штатний
інтерфейс Home Assistant: без власних панелей, карток і стилів.

[![Відкрити цей репозиторій у HACS.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=DmytroZamkovyi&repository=calendar_sync&category=integration)
[![Додати цю інтеграцію в Home Assistant.](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=calendar_sync)

> **Статус: у розробці.** Ядро синхронізації й тести готові
> (`core/`). Шар інтеграції з Home Assistant
> (налаштування, сутності, служби) ще не написаний, тому кнопки вище запрацюють лише
> після релізу.

## Встановлення (після релізу)

1. HACS → ⋮ → **Користувацькі репозиторії** → додайте цей репозиторій, категорія
   **Integration** (або натисніть кнопку HACS вище).
2. Завантажте **Calendar Sync** і перезапустіть Home Assistant.
3. **Налаштування → Пристрої та служби → Додати інтеграцію → Calendar Sync**
   (або натисніть другу кнопку вище).

## Як це працює

1. Додайте пару: виберіть **календар 1** і **календар 2**.
2. Увімкніть потрібні напрямки: «1 → 2» і «2 → 1». Обидва ввімкнені: двостороння
   синхронізація. Один: дзеркало (односторонній режим).
3. За потреби додайте правила для кожного напрямку.
4. Задайте вікно синхронізації (за замовчуванням 7 днів назад і 14 вперед).

Кожен цикл для кожної події порівнюється *знімок останньої синхронізації /
календар 1 / календар 2*, і переносяться лише ті поля, що змінились (назва, час,
опис, місце).

### Правила

Правило це одна умова й одна дія, окремо для кожного напрямку.

- **Умови:** назва, опис або місце містять / дорівнюють / починаються / закінчуються /
  збігаються з регулярним виразом; подія на весь день; тривалість більша або менша за N хвилин;
  день тижня; години початку.
- **Дії:** пропустити подію; змінити назву, опис або місце за шаблоном
  (`{summary}`, `{description}`, `{location}`, `{start}`, `{end}`); очистити опис або місце;
  зсунути час на N хвилин.

Порожній набір правил копіює все як є.

### Дзеркало (один напрямок)

Якщо календар, у який копіюються події, змінюють вручну, можна вибрати, що робити:
**ігнорувати** такі зміни або **відкочувати** їх до стану джерела.

### Конфлікти

Якщо те саме поле змінили з обох боків, діє політика: перемагає календар 1,
перемагає календар 2 або питати.

### Безпека

- Змінюються лише події, які інтеграція створила або прив'язала. Чужі події в календарі не чіпаються.
- Якщо за один цикл треба видалити забагато подій, видалення блокуються, доки ви їх не підтвердите.
- Помилка запису не ламає зв'язок між подіями, спроба повторюється в наступному циклі.
- Є «пробний запуск», який лише показує, що було б зроблено.

### Обмеження

- Календарі лише для читання (CalDAV, свята, календарі інших інтеграцій) можуть бути тільки джерелом.
- Штатна інтеграція Google Calendar не вміє редагувати події, тому зміни в ній записуються
  як «видалити й створити заново».
- Повторювані події синхронізуються як окремі екземпляри в межах вікна, а не як серія.
- Учасники, нагадування й вкладення не синхронізуються.
